# MalalphAI

**Turning talk into direction.**

MalalphAI (Mala Alpha AI) turns FX forum chatter into a probability forecast for the US dollar. Nimble fetches live forum threads, Gemini reads every comment, and a small Bayesian "pot" works out where USDEUR, USDJPY, USDGBP and USDCAD are heading over 5, 22 and 66 trading days.

Live demo: https://zhanghaoquan.github.io/malalphai/
